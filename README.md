# VASHI birki — сайт-каталог

Демо-сайт «Ваши бирки»: каталог восьми видов продукции с печатью логотипа и расчёт стоимости по прайсу.

**Статус:** демо для согласования. Заявки пока нельзя отправить — нет подтверждённых контактов. Список того, что нужно от владельца, — в [CHECKLIST.md](CHECKLIST.md).

## Как открыть

`index.html` — готовый сайт. Рядом должны лежать папки `shades/` (фото оттенков для окна выбора цвета), `works/` (фото «Наших работ») и файл `og.jpg` (превью ссылки в мессенджерах). Стили Tailwind уже собраны внутрь страницы, CDN не нужен; из интернета грузятся только шрифты Google.

`index.dev.html` — та же страница с Tailwind через CDN, для правок. После правок стили собираются заново: `node tools/compile_tw.js index.dev.html tw.css`, содержимое `tw.css` — в `<style>` после своих стилей вместо CDN-скрипта.

## Что на сайте

- Первый экран, под ним бегущие ленты VASHI.BIRKI; каталог из восьми карточек с фото и «Рассчитать →», «Виды лент», «Наши работы», «Как заказать» (бордовая панель), «Частые вопросы» (тиражи и цены макета — из прайса), «Контакты».
- Общая заявка: «Добавить в заявку» в карточке товара, несколько товаров одним сообщением в WhatsApp; хранится в браузере покупателя.
- Примерка: текст покупателя на ленте выбранного оттенка и цвета печати (примерный вид).
- На телефоне — нижняя панель «Рассчитать заказ» / «Заявка» и WhatsApp; на компьютере — кнопка заявки в углу.
- «Наши работы»: карусель на телефоне (свайп, стрелки, точки, счётчик), на широком экране — ряд без листания; любое фото открывается крупнее.
- Экран товара: основные параметры (у лент — материал: глянцевый или матовый сатин), поля «Цвет ленты/наклейки» и «Цвет печати» с кнопкой «Выбрать цвет» (открывается окно с образцами, поиском по названию и кнопкой «Подобрать с менеджером»), тираж с ценой, «Посмотреть прайс», раздел «Оформление и пожелания», итог внизу.
- Кнопка «Скопировать заявку» собирает текст из выбранных параметров.
- Раздел «Контакты» и кнопка отправки появляются автоматически, когда заполнен `CONTACTS`.

## Где что менять в `index.html`

| Что | Где |
| --- | --- |
| Цвета и шрифты | `:root` в начале `<style>`: молочный `--milk`, бордовый `--wine` / `--wine-deep`, текст `--ink` / `--muted`, линии `--line`; шрифты Prata (заголовки) и Manrope (текст) |
| Контакты | `const CONTACTS = { whatsapp, telegram, instagram, phone }` |
| Цены | блок «ПРАЙС: единственный источник цен» (`RIBBON`, `SILICONE`, `VINYL`, `TISSUE`, `WRAP`, `PHONE`, `TAPE`, `CHOCO`) |
| Товары, параметры, стоимость макета | массив `PRODUCTS` |
| Фотографии | `window.PHOTOS`: `hero`; карточки `ribbon`, `silicone`, `vinyl`, `phone`, `tape`, `choco` (у тишью и упаковочной бумаги пока иллюстрации `illo`); `rp_01…rp_10` — фото риббонов для палитры печати лент; `g_*` — «Наши работы» |
| Палитры | `SATIN_CLASSIC` (59 оттенков глянцевого сатина) и `SATIN_MATTE` (15 оттенков матового) — каталог ribbon-gold.shop, с ширинами, у каждого `id` и ссылка `src` на позицию; `STICKER_SHADES` (основа наклеек по формату); `RIBBON_PRINT` и `STICKER_PRINT` (печать, фото риббонов клиентки); `TAPE_PRINT` (скотч) |
| Фото оттенков | файлы `shades/<id>.jpg` (98 шт., квадрат 360 px, кадры каталога ribbon-gold.shop), например `shades/sc-alyij-kardinal.jpg`; список файлов — `window.SHADE_FILES`. Нет файла — в окне выбора «фото уточняется» |
| Подложка стикеров | `extras` товара `phone`: односторонняя 16 ₽/шт., двусторонняя 18 ₽/шт. (в сумму стикеров не входит) |
| «Наши работы» | массив `WORKS`: `{ photo: 'ключ', cap: 'подпись', ratio: ширина / высота }`; режим листания включается сам |

Карточки, список тиражей, прайс, итог и текст заявки берут цены из одного места, поэтому менять их нужно только в блоке прайса.

## Правила расчёта

- Считаются только тиражи из прайса. Промежуточные тиражи, силикон 501–999 м и формат 75 × 120 мм показываются как «По запросу».
- Доступные оттенки зависят от материала и ширины (ленты) или формы и размера (наклейки); несовместимый выбранный цвет сбрасывается с подсказкой. В заявку уходит точное название оттенка.
- Матовый сатин: цены уже показаны с наценкой +10% (`MATTE_MARKUP`), к итогу она второй раз не прибавляется.
- Полная заливка (+30%) и подложка 16 ₽ не прибавляются к сумме — до подтверждения базы расчёта.
- Разработка макета показывается отдельной строкой и не входит в сумму продукции.

## Проверка

```
npm i puppeteer
node tests/check.js      # товары, клавиатура, суммы, выбор цвета, подложка, заявка, контакты, работы (97)
node tests/features.js   # ленты, порядок секций, FAQ, подвал, примерка, общая заявка, нижняя панель (96)
node tests/picker.js     # окно выбора цвета на 360–1280 px (55)
node tests/works.js      # «Наши работы»: карусель и просмотр (60)
node tests/style.js      # палитра, шрифты, кегль, фокус (60)
node tests/hero.js       # первый экран (25)
```

Скриншоты складываются в `tests/shots/` (в git не попадают). Сайт можно подменить переменной `SITE_URL`, браузер — `CHROME_PATH`.
