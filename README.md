# VASHI birki — сайт-каталог

Демо-сайт «Ваши бирки»: каталог восьми видов продукции с печатью логотипа и расчёт стоимости по прайсу.

**Статус:** демо для согласования. Заявки пока нельзя отправить — нет подтверждённых контактов. Список того, что нужно от владельца, — в [CHECKLIST.md](CHECKLIST.md).

## Как открыть

Один файл `index.html`: откройте его в браузере. Нужен интернет — Tailwind CSS и шрифты Google загружаются с CDN. Фотографии встроены в файл.

## Что на сайте

- Первый экран, каталог из восьми карточек, блок «Как заказать».
- Экран товара: основные параметры, тираж с ценой, «Посмотреть прайс», раздел «Оформление и пожелания», итог внизу.
- Кнопка «Скопировать заявку» собирает текст из выбранных параметров.
- Раздел «Контакты» и кнопка отправки появляются автоматически, когда заполнен `CONTACTS`.

## Где что менять в `index.html`

| Что | Где |
| --- | --- |
| Контакты | `const CONTACTS = { whatsapp, telegram, instagram, phone }` |
| Цены | блок «ПРАЙС: единственный источник цен» (`RIBBON`, `SILICONE`, `VINYL`, `TISSUE`, `WRAP`, `PHONE`, `TAPE`, `CHOCO`) |
| Товары, параметры, стоимость макета | массив `PRODUCTS` |
| Фотографии | `window.PHOTOS` (ключи `hero`, `ribbon`, `vinyl`, `phone`); у товара без фото задаётся `photo: 'ключ'` вместо `illo` |

Карточки, список тиражей, прайс, итог и текст заявки берут цены из одного места, поэтому менять их нужно только в блоке прайса.

## Правила расчёта

- Считаются только тиражи из прайса. Промежуточные тиражи, силикон 501–999 м и формат 75 × 120 мм показываются как «По запросу».
- Матовый сатин (+10%), полная заливка (+30%) и подложка 16 ₽ не прибавляются к сумме — до подтверждения базы расчёта.
- Разработка макета показывается отдельной строкой и не входит в сумму продукции.

## Проверка

```
npm i puppeteer
node tests/check.js
```

Скрипт открывает сайт на ширинах 360, 390, 430 и 1280 px и проверяет переполнение, открытие и закрытие товаров, работу при открытой клавиатуре, контрольные суммы и копирование заявки.
