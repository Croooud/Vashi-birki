# VASHI birki — сайт-каталог

Демо-сайт «Ваши бирки»: каталог восьми видов продукции с печатью логотипа и расчёт стоимости по прайсу.

**Статус:** демо для согласования. Заявки пока нельзя отправить — нет подтверждённых контактов. Список того, что нужно от владельца, — в [CHECKLIST.md](CHECKLIST.md).

## Как открыть

Один файл `index.html`: откройте его в браузере. Нужен интернет — Tailwind CSS и шрифты Google загружаются с CDN. Фотографии встроены в файл.

## Что на сайте

- Первый экран, каталог из восьми карточек с фото работ, под ним «Виды лент» с ценой «от» и кнопкой выбора, блок «Как заказать».
- «Наши работы»: карусель на телефоне (свайп, стрелки, точки, счётчик), на широком экране — ряд без листания; любое фото открывается крупнее.
- Экран товара: основные параметры (у лент — материал: глянцевый или матовый сатин), отдельный выбор «Цвет ленты/наклейки» и «Цвет печати», тираж с ценой, «Посмотреть прайс», раздел «Оформление и пожелания», итог внизу.
- Кнопка «Скопировать заявку» собирает текст из выбранных параметров.
- Раздел «Контакты» и кнопка отправки появляются автоматически, когда заполнен `CONTACTS`.

## Где что менять в `index.html`

| Что | Где |
| --- | --- |
| Цвета и шрифты | `:root` в начале `<style>`: молочный `--milk`, бордовый `--wine` / `--wine-deep`, текст `--ink` / `--muted`, линии `--line`; шрифты Prata (заголовки) и Manrope (текст) |
| Контакты | `const CONTACTS = { whatsapp, telegram, instagram, phone }` |
| Цены | блок «ПРАЙС: единственный источник цен» (`RIBBON`, `SILICONE`, `VINYL`, `TISSUE`, `WRAP`, `PHONE`, `TAPE`, `CHOCO`) |
| Товары, параметры, стоимость макета | массив `PRODUCTS` |
| Фотографии | `window.PHOTOS`: `hero`; карточки `ribbon`, `silicone`, `vinyl`, `phone`, `tape`, `choco` (у тишью и упаковочной бумаги пока иллюстрации `illo`); `rp_01…rp_10` — фото риббонов для палитры печати лент; `g_*` — «Наши работы» |
| Палитры | `SATIN_COLORS` (цвета сатина), `RIBBON_PRINT` (печать на лентах, плитки с фото), `STICKER_BASE` (основа наклеек по формату), `STICKER_PRINT` (6 цветов печати наклеек), `TAPE_PRINT` (скотч) |
| «Наши работы» | массив `WORKS`: `{ photo: 'ключ', cap: 'подпись', ratio: ширина / высота }`; режим листания включается сам |

Карточки, список тиражей, прайс, итог и текст заявки берут цены из одного места, поэтому менять их нужно только в блоке прайса.

## Правила расчёта

- Считаются только тиражи из прайса. Промежуточные тиражи, силикон 501–999 м и формат 75 × 120 мм показываются как «По запросу».
- Матовый сатин: цены уже показаны с наценкой +10% (`MATTE_MARKUP`), к итогу она второй раз не прибавляется.
- Полная заливка (+30%) и подложка 16 ₽ не прибавляются к сумме — до подтверждения базы расчёта.
- Разработка макета показывается отдельной строкой и не входит в сумму продукции.

## Проверка

```
npm i puppeteer
node tests/check.js   # переполнение, товары, клавиатура, суммы, палитры, заявка, «Наши работы» (81 проверка)
node tests/style.js   # палитра, шрифты, минимальный кегль, фокус (60)
node tests/hero.js    # первый экран на 360–1440 px (25)
node tests/works.js   # листание и просмотр работ на 360–1440 px (46)
```

Скриншоты складываются в `tests/shots/` (в git не попадают). Сайт можно подменить переменной `SITE_URL`, браузер — `CHROME_PATH`.
